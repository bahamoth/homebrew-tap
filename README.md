# homebrew-tap

Homebrew formulae for [bahamoth](https://github.com/bahamoth)'s tools.

```sh
brew install bahamoth/tap/wimcc
```

Formulae under `Formula/` are published automatically by the
[wimcc release pipeline](https://github.com/bahamoth/whats-in-my-cc)
(cargo-dist `publish-homebrew-formula` job) — do not edit them by hand.
